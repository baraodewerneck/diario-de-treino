# Treino ULPPL - como publicar no GitHub Pages

1. Crie um repositório no GitHub (pode ser privado só se o seu plano permitir Pages; público funciona sempre).
2. Envie todos os arquivos desta pasta para a raiz do repositório: index.html, manifest.webmanifest, sw.js, icon.svg, icon-192.png, icon-512.png, icon-maskable-512.png.
3. Em Settings > Pages, escolha "Deploy from a branch", branch main, pasta / (root), e salve.
4. Aguarde 1 a 2 minutos e abra https://SEU-USUARIO.github.io/NOME-DO-REPO/ no Chrome do Android.
5. Menu do Chrome > "Instalar app" (ou "Adicionar à tela inicial").

Atualizações: depois de alterar o index.html, mude o número em const C='treino-v1' no sw.js (por exemplo treino-v2) para o celular baixar a versão nova.

Dados: ficam no navegador do aparelho. Use a aba Dados para exportar um backup de tempos em tempos.
